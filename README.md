# MetronomeNext

**Live Demo:** [https://metronome-next.vercel.app](https://metronome-next.vercel.app)

MetronomeNext is a browser-based metronome built with React and TypeScript using Next.js.
It runs entirely on the frontend and uses the Web Audio API for accurate timing and consistent interval scheduling.

## Features

* Adjustable tempo (BPM)
* Customizable beat count
* Customizable beat sound
* Accent control for the first beat
* Volume adjustment
* Light and dark theme switching
* Keyboard shortcuts:

  * Arrow keys for tempo control
  * Spacebar to start or pause

## Technical Details

* Built with React
* Written in TypeScript
* Powered by Next.js
* Uses the **Web Audio API** to keep precise time instead of relying on setInterval
